# Appium CI の依存物の記録

## 目的

Issue #233 の調査に使うため、Windows と macOS の Appium CI で実際にインストールされた Appium 本体とドライバーのファイルを記録します。インストール後に `appium-dependency-inventory.json` を生成し、既存の `ui-appium-<platform>-evidence` 成果物に含めます。次の実行で取得した記録は、過去の CI の依存物を示すものではありません。

## 記録する内容

- Appium 本体と、`node_modules` の直下または `@scope` の直下にあるパッケージの `package.json` の相対パス、名前、バージョン。
- `.node`、`.dll`、`.dylib`、`.so`、`.exe` で終わるファイルの相対パス、バイト数、SHA-256。
- 追跡しなかったシンボリックリンクやジャンクションの相対パス。

絶対パス、package.json のその他の項目、ファイル本体は保存しません。走査先がない場合や読み取れない場合は失敗し、部分的な一覧を成功と扱いません。リンク先をたどらないため、リンクが記録された場合は対象外の範囲を別途確認してください。

## 未確認の範囲

拡張子での一覧は、拡張子のない実行ファイル、版番号付きの共有ライブラリ、アーカイブ内のファイル、インストール時に利用された外部ツールを網羅しません。ファイルのハッシュから、Brotli の同梱や脆弱性の有無は判断できません。各 OS の依存物の実体と通信・展開経路を別途調べる必要があります。Node.js の最低版検査や一覧取得の成功だけでは、Issue #233 を完了にできません。
